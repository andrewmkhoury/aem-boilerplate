# inquiry-form

Custom **custom** block. Purpose: intro text beside a booking inquiry form with honeypot, optional reCAPTCHA and submit.

## Authoring (Document Authoring)

Model: `configuration`

Key/value rows (label in the first cell, value in the second): a one-cell intro row (heading + text); then one row per field: Label | type | value [| name]. type is text, email, tel, textarea, hidden, honeypot, recaptcha or submit; end a label with * for required or (optional) for optional; value is the textarea default text, input placeholder, hidden value or reCAPTCHA site key. Config rows: action | URL, method | post, success | message, error | message.

## Supported variations

No variations.
