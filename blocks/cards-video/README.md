# cards-video

Custom **cards** block. Purpose: grid of cards that each play a video file (mp4) in place when clicked.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card; cells: image | body (optional title, subtitle, and a link to a video file such as .mp4, whose text becomes the play button label). A body holding only the video link puts a play button over the image.

## Supported variations

| Variation | Option class |
| --- | --- |
| Text Over Image | `text-over-image` |
