# cards-contact

Custom **cards** block. Purpose: boxed contact/payment tiles, each a short label over a handle or link (e.g. Zelle, Venmo, Instagram).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tile; cells: label | link (or one cell with a label paragraph and a link paragraph); external links open in a new tab.

No variations.
