# columns-embed

Custom **columns** block. Purpose: text column (heading, text, link) beside an embedded media player such as a Spotify playlist.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, two cells: text cell (heading, text, links) | embed cell holding only the share link of a Spotify, YouTube or Vimeo item, which becomes a lazy-loaded iframe.

In the text cell, a paragraph holding only a link is styled as the glow-ring CTA, the first other paragraph is the lead, and a number opening the lead (e.g. "84 Song Repertoire") is highlighted in the accent color. Spotify players default to the dark theme (`theme=0`) unless the share link sets one.
