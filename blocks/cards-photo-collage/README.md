# cards-photo-collage

Custom **cards** block. Purpose: photo gallery: sticky full-viewport scroll-driven collage on tablet/desktop (photos scatter out of a stack as you scroll), horizontal swipe slider on mobile, every photo opens in a keyboard-accessible lightbox.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per photo; the single cell holds an image (alt text required) linked to its full-size file, either as a link wrapping the image or a link placed next to it. Without a link the image itself opens in the lightbox.

No variations.
