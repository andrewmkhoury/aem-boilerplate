# Hero Video

A full-screen hero with a muted, looping background video (dimmed) behind a large centered title.

## Authoring

| hero-video |
| --- |
| Link to the background video file (`.mp4`/`.webm`), or an image |
| Title (heading), optional subheading and call-to-action |

- The video plays muted and loops; with reduced motion turned on it does not autoplay.
- Without a video link, an image in the first row is used as the background.
